grep-hygiene · hay

hay — a ranked grep
for coding agents

Same matches as rg. Different order. hay returns exactly what ripgrep returns, reordered so the line that declares the thing you asked about comes first.

Rust · MSRV 1.85 no index · no daemon · no state first on 4/4 usable corpora differential-tested vs rg

why hay

One opinion replaces shelf order.

the problem

Path order is shelf order.

ripgrep is prior-free by design: it hands agents every match in walk order. An agent reads the first page and acts on it — so a dead planning doc sorting before the real function is not cosmetic.

the choice

Definitions outrank mentions.

hay adds exactly one opinion: a line that declares the thing beats a line that merely says it. Declaration keywords, typed-declaration shapes, key styles — scored, measured, ablatable.

the honesty

The win is stated as weak.

The benchmark's ground truth is declarations — the thing hay optimises. So the page shows margins with intervals, cross-checked by Fisher randomization, and links the behavioural evaluation whose truth nobody designed around the tool.

what it does

A ranked grep, kept deliberately narrow.

drop-in shape

rg-compatible I/O

path:line:text, globs, types, context windows, JSON Lines — combined short flags included, via lexopt.

the product

Definition-first ranking

Three signals — definition, path prior, damped term frequency. Each has an ablation switch, because a signal you can't turn off is a belief.

for agents

Loud, not silent

Candidate cap? stderr notice + exit 2. Flag refused? The reason, out loud. A quiet wrong answer is the defect this tool exists to prevent.

verified

Differential-tested

A harness proves hay returns exactly ripgrep's matches on every change to walking, matching, or output. Order is the only degree of freedom.
