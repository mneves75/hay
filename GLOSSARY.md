# hay retrieval

hay finds matching content and filenames within an explicitly chosen search scope.

## Language

**Content match**: A line satisfying the requested content pattern. A filename hit is not a content match.

**Filename hit**: A file whose name satisfies a filename query.

**Search scope**: The paths and filtering rules determining which files a search considers.

**Complete search**: A search that considered every eligible file without an unreported failure.

**Ranked page**: A requested portion of the ordered results. A limited page does not establish that the search was incomplete.

**Open feedback**: An explicitly recorded file opening offered as an optional relevance signal.
