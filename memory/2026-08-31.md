# 2026-08-31 — release-policy rollback audit

An independent supply-chain review invalidated the previous “no P0–P3” closeout. A `push.tags`
release loads its workflow from the tagged commit, so a tag aimed at history could omit the new
gate while still building, attesting, and drafting a release. The local workflow now uses manual
dispatch from `main`; exact-SHA CI authorizes the run, an environment-scoped GitHub App creates the
lightweight tag at that same SHA, and the default `GITHUB_TOKEN` never receives contents write.
The requested tag's base version must match Cargo metadata before the App can create it. Homebrew
provenance verification is bound to `refs/heads/main` plus the tag's exact source digest.

The local policy is intentionally fail-closed until external controls exist. Before any release,
protect `main`; create a `v*` tag ruleset whose only bypass actor is the release App; restrict the
`release` environment to `main` and place the App private key there; install the App only on this
repository with contents write; then negative-test a manual `v9.9.9` push and run one beta dispatch.
The repository currently has no branch/tag rulesets and no `release` environment, so production is
blocked. No GitHub setting, credential, commit, push, tag, deploy, or release was changed here.

A second review found that private observations used transcript CWDs as repository identities.
Nested CWDs now resolve to the nearest real Git root, and judgments are rebased before grouping,
with positive controls in both harvester and runner. The frozen private corpus is absent, so the
historical 713/702 aggregate cannot be revalidated locally and no longer authorizes release.

The closeout autoreview reproduced one further release-integrity defect: Bash disables `errexit`
inside command substitution, so `brew-formula.sh` could continue after a rejected checksum manifest
and print an empty hash. A planted wrapper-level control failed before the fix; download, manifest,
and attestation errors now return explicitly, and the same control passes.
