# 2026-08-25 — 0.1.3 hardening release

Objective: make the existing product and release path fail closed without changing ranking signals,
weights, or the pre-registered gate. The gate still fails; this release does not disguise that fact.

The review found and fixed issues at four boundaries:

- Candidate retention over 20,000 matches now exits 2 and says selection is by prescore. JSON
  context offsets and zero-width submatches match the contract, and context re-read failures are
  errors rather than silent omissions.
- Context is re-opened through a capability anchored before the walk. A positive control reads an
  in-root file; outside paths and a matched path replaced by an outside symlink are rejected.
- The public SWE-Explore harness used remote instance IDs in recursive cache cleanup and remote
  ground-truth paths in filesystem probes. Instance IDs, GitHub slugs, 40-hex commits, and Git
  relative paths are now validated before those operations; live-shaped inputs pass and traversal,
  absolute, NUL, and platform-separator inputs fail in self-tests.
- The manual's no-result state appeared over real matches, wide tables overflowed a 375px viewport,
  and a missing favicon generated a network error. Real Chromium E2E now verifies hit/no-hit,
  Escape, theme, navigation, mobile and desktop layout, zero runtime errors, and zero failed
  requests. Clipboard contents could not be read back because the browser denied that permission.

Release hardening adds a compile-time unsafe prohibition, tested ast-grep rules plus a blocking
pre-commit hook, a 17-case differential matrix, and GitHub artifact attestations in the tag build.
The dependency and workflow review found no known vulnerabilities or unpinned Actions.

Evidence before closeout: Rust format/clippy/tests/build/MSRV passed (37 unit + 13 CLI);
differential 17/0; all nine Bun self-tests, typecheck, ast-grep positive controls, generated-report
freshness, shellcheck, actionlint, Bun/Cargo/site audits, gitleaks history scan, site build, and
release-binary E2E passed. P3 autoreview returned no findings; an independent fresh-context
verifier returned PASS after rerunning the core Rust, differential, TypeScript, ast-grep, audit,
and shell gates. Five atomic commits reached `main`; remote CI passed all seven jobs. The
`v0.1.3-beta1` and annotated `v0.1.3` tags resolve to the same reviewed commit, and each release
workflow passed five platform builds plus draft creation with ten assets. For both tags, the arm64
macOS archive passed its published checksum, strict provenance policy (repository, signer workflow,
tag ref, source commit, GitHub-hosted runner), binary version check, archive-content inspection,
and real search smoke test. The production GitHub Release remains draft and unpublished by explicit
user choice. The pre-registered behavioural ranking gate still fails and remains unchanged.
