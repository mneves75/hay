Meet hay, a ranked grep for coding agents. Ripgrep’s matching engine, with likely definitions first—and one result per file before a file’s second line.

Install hay See how it works

Complete searches preserve the normalized ripgrep match set. Candidate caps or read errors return exit 2, so an incomplete answer stays explicit.
